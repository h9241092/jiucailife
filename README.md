# 韭菜人生模擬器｜JIU-CAI LIFE

目前版本：`v1.0.2`

這是一款以台股、美股、ETF 與加密貨幣為舞台的純文字投資人生模擬器。靈感來自 yakyulife（棒球人生模擬器）

👉 **[點我直接遊玩](https://jiucai-life-simulator.mmrichdog.workers.dev/)**

## 遊戲特色

- 每季閱讀市場事件、判讀情報，再到獨立券商畫面自由買賣。
- 種子碼會重現角色體質、事件順序與市場行情。
- 工作、健康、壓力、家庭、信用與投資知識會共同改變人生走向。
- 以 31 歲前累積三千萬元可投資淨資產、達成提前退休為主要目標。

## 隱私

遊戲只記錄種子碼、遊戲版本與玩家在遊戲內的選擇和結果，不收集角色姓名或裝置指紋。原始局次保存 180 天，詳見 [資料與隱私說明](PRIVACY.md)。
