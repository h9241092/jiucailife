# 韭菜人生模擬器｜JIU-CAI LIFE

目前版本：`v1.0.6`

這是一款以台股、美股、ETF 與加密貨幣為舞台的純文字投資人生模擬器。靈感來自 yakyulife（棒球人生模擬器）


## 立即遊玩
👉 https://jiucai-life-simulator.mmrichdog.workers.dev/

## 遊戲特色

- 每季閱讀市場事件、判讀情報，再到獨立券商畫面自由買賣。
- 種子碼會重現角色體質、事件順序與市場行情。
- 工作、健康、壓力、家庭、信用與投資知識會共同改變人生走向。
- 以 31 歲前累積三千萬元淨資產並達成網路口口聲聲的提前退休為主要目標。
