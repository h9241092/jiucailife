# 韭菜人生模擬器｜JIU-CAI LIFE

目前版本：`v1.0.4`

這是一款以台股、美股、ETF 與加密貨幣為舞台的純文字投資人生模擬器。靈感來自 yakyulife（棒球人生模擬器）


## 立即遊玩
👉 https://jiucai-life-simulator.mmrichdog.workers.dev/

## 遊戲特色

- 每季閱讀市場事件、判讀情報，再到獨立券商畫面自由買賣。
- 種子碼會重現角色體質、事件順序與市場行情。
- 工作、健康、壓力、家庭、信用與投資知識會共同改變人生走向。
- 以 31 歲前累積三千萬元淨資產並達成網路口口聲聲的提前退休為主要目標。

## 遊玩方式

- 可查[WIKI](https://github.com/h9241092/jiucailife/blob/main/WIKI.md)

## v1.0.4 更新內容

- 四種核心事件角度開始產生不同的行情訊號、判讀難度、影響時間與流量收益。
- 「市場先動了」放大訊號但更難判讀；「後座力才開始」讓主要標的影響多延續一季。
- 「人人突然變專家」提高跟上流量的收入與代價；「早知道最貴」較容易看懂方向，但可掌握的行情幅度較小。
- 事件畫面新增角度效果提示，並完成桌機與手機版排版。

## 隱私

遊戲只記錄種子碼、遊戲版本與玩家在遊戲內的選擇和結果，不收集角色姓名或裝置指紋。原始局次保存 180 天，詳見 [資料與隱私說明](PRIVACY.md)。
